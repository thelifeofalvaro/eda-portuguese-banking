# 📊 Análisis exploratorio de una campaña de marketing bancario

Análisis exploratorio de una campaña de marketing de una entidad bancaria con Python, orientado a identificar patrones de aceptación y obtener conclusiones que puedan servir para optimizar futuras campañas y productos.

## 🎯 Objetivo

El objetivo del proyecto es analizar el comportamiento de los clientes contactados durante una campaña de marketing y estudiar qué características están asociadas con una mayor o menor aceptación.

Para ello se analizan variables relacionadas con:

- Perfil demográfico.
- Situación laboral.
- Nivel educativo.
- Situación financiera.
- Historial de contactos.
- Características de la campaña.
- Comportamiento relacionado con la web.

El análisis busca responder, entre otras, preguntas como:

- ¿Qué perfiles de clientes muestran una mayor aceptación?
- ¿Existen diferencias según edad, situación laboral o nivel educativo?
- ¿Influyen las características de la situación financiera?
- ¿Qué relación existe entre el número y duración de los contactos y la aceptación?
- ¿Se observan diferencias relevantes según el momento de la campaña?
